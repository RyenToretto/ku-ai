> File path convention: `~/.smart_ai/{project-slug}/handoff-{ISO-UTC-timestamp}.md`

## What "lossy-compress" means in §3

You will lose state in any handoff. The goal is to lose the **right** state:

| KEEP | DROP |
|------|------|
| Why a decision was made (rationale) | The 5 alternatives debated to get there |
| Final API contract / type signature | The 3 iterations to land on it |
| Verified gotchas ("backend rejects raw `data:image/...` prefix") | Step-by-step of HOW you discovered the gotcha |
| The user's preference / style ("avoid ternaries, use template strings") | Every code snippet shown as evidence |

A good §3 entry reads like a postmortem bullet, not a chat log.

## Common mistakes to avoid

- ❌ Writing "see chat history" — the new session has NO chat history
- ❌ Listing 30+ files in §4 without grouping — make it scannable
- ❌ Marking ✅ on §5 items that you did NOT actually run
- ❌ Putting the file path in §7 as `~/.smart_ai/…` and forgetting to substitute the placeholders — paste the literal full path
- ❌ Including secrets, tokens, API keys — use `<REDACTED>` placeholders
